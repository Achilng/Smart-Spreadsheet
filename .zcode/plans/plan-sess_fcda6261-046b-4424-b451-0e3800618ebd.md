# 图片对比页实施计划

## 需求定稿（已确认）

- **入口**：右键菜单新增"对比"（画廊/表格/分组/重复项共用 `ContextMenu.svelte`，一处添加全视图生效），位置在"选中相同画师串"之后。
- **窗口**：独立 Tauri 窗口（label `compare`，标题"图片对比"），单例——已打开则聚焦并切换样本；机制完全照抄工具箱（后端命令建窗 + `main.ts` URL 参数分流）。
- **页面结构**：顶部样本区（2048 大图 + 元数据摘要 + 可折叠提示词），下方 5 个分区；每区 = 标题 + 总数 + 预览网格（首批约 24 张）+ 页内"加载更多"；样本自身不出现于任何分区；空态如实文案（样本无画师串/无 VIBE/库中无匹配）。
- **点击分区图片 → 页内并排对比**：切换到"样本 vs 该图"并排视图——两张大图同屏，提示词逐项差异高亮（按逗号拆 tag、集合比较、标出仅样本有/仅该图有），生成参数对比表（模型/采样器/噪声调度/步数/Guidance/CFG Rescale/种子/尺寸，差异值高亮），附"在主画廊中查看"按钮（复用 `toolbox://open-row` 事件 + `focusMainWindow`），返回按钮回到分区列表。
- **五个分区**：
  1. **相同画师串**：`TRIM(artists)` 精确相等（与"只看当前画师串"同口径）；附"去主画廊看全部"（跨窗口事件让主窗口执行现有 `focusArtistFilter`）。
  2. **画师串 × 模型**：同一集合按 `generation_model` 分组，先显示各组数量徽标，每组独立预览与加载更多。
  3. **相同 VIBE 组 · 提示词不同**：`vibe_signature` 相等且提示词不同。
  4. **相同提示词 · VIBE 组不同**：提示词相等且 `vibe_signature` 不同（NULL 视为空串；样本无 VIBE 时仅显示有 VIBE 的同提示词图）。
  5. **相同提示词 · 模型版本不同**：提示词相等且模型不同，按模型分组（呈现同分区 2）；NULL/无法识别模型归入"未知模型"组。
- **"提示词相同"统一定义**：正向 + 角色提示词在去掉 CR/LF、去首尾空白、不区分大小写后逐字一致；NULL 视为空串；负向提示词不参与判定。

## 实施步骤（分支 `agent/minimal-ui`，每步一个 commit 并推送 GitHub）

### 1. 后端：窗口命令 + 数据查询 + 测试
- `src-tauri/src/app/commands.rs` 仿 `open_toolbox_window`（L1228）新增 `open_compare_window`：label `compare`，URL `index.html?window=compare`，1080×760（min 860×600），decorations:false；已存在则 show/unminimize/focus。注册进 `lib.rs`。
- 新增 `src-tauri/capabilities/compare.json`：`windows: ["compare"]`，权限照 `toolbox.json` 去掉 `updater:default`/`process:allow-restart`/`dialog:default`（保留窗口控制与 destroy——工具箱关闭失效的教训）。
- `src-tauri/src/db/query.rs` 新增：
  - `compare_sample(row_id)` → 样本 `RowRecord` + 各分区总数 +（分区 2/5）按 `generation_model` 的 GROUP BY 分组计数；
  - `compare_section_rows(row_id, kind, offset, limit, model: Option<String>)` → 行列表 + 总数 + hasMore，`model` 用于模型分组分区内取行。
  - SQL 要点：artists 匹配复用 `row_ids_with_artists`（L372-386）的表达式；提示词相等用 `lower(replace(replace(trim(COALESCE(positive_prompt,'')),char(13),''),char(10),'')) = ?`（角色提示词同理，参数为 Rust 侧同规则预计算的样本值）；所有分区 `AND id <> 样本`。
- Rust 回归测试：提示词规范化相等（CRLF/大小写/首尾空白/NULL）、五分区命中与排除规则、样本排除、空画师串/无 VIBE/无模型边界、模型分组计数。

### 2. 前端：窗口挂载 + 样本区
- `src/main.ts` 加 `window=compare` 分支，挂载 `src/lib/views/compare/CompareWindow.svelte`。
- 标题栏复用 `WindowControls` + `data-tauri-drag-region`（照 `ToolboxWindow.svelte` L291）。
- 样本传递用拉推结合（照 `toolbox://request-selection` 模式）：右键时主窗口存样本 ID 并 `emitTo("compare", "main://compare-sample", { rowId })`；对比窗口挂载时 `emitTo("main", "compare://request-sample")` 索取一次，避免建窗竞态。
- 样本区：左侧大图用 `detailPreviews`（`progressive-images.ts`），右侧摘要：文件名、分辨率、时间、画师串（可复制）、VIBE 数、模型徽章（`modelVersionBadge`）、采样器/步数/CFG/种子（有则显示）、三类提示词可折叠 + 复制。

### 3. 前端：五个分区
- 轻量 `CompareCard.svelte`：`Thumbnail`（rowId + hasImage）+ 模型徽章 + VIBE 数叠加，不依赖画廊全局 store。
- `CompareSection.svelte`：标题 + 总数 + 网格 + "加载更多（还有 N 张）"（照 `GroupBrowseView.svelte` 的模式）；模型分组变体按组渲染子标题（徽章文案 + 原始模型名）。
- 分页状态照 `section-cache.ts` / `duplicate-browse-store` 的签名失效模式，换样本自动失效重载。
- "去主画廊看全部"（分区 1）：`emitTo("main", ...)` 让 `Workspace.svelte` 执行现有画师串筛选跳转；其余分区第一版仅页内加载更多。
- 新增 `src/lib/api/compare.ts` 封装两个命令的类型与调用。

### 4. 入口 + 并排对比视图
- `ContextMenu.svelte` 新增"对比"项：主窗口存样本 → `invoke("open_compare_window")` → 发样本事件。
- `SideBySide.svelte`：样本固定左侧、点击图右侧（各用 `detailPreviews`，可再放大到原图 `originalImages`）；提示词 diff（新增 `src/lib/utils/prompt-diff.ts`：按逗号拆分、trim、集合比较，输出"仅样本有/仅该图有/相同"三组，三个提示词字段分别展示）；参数对比表差异高亮；"在主画廊中查看"按钮；返回分区列表。

### 5. 文档与验证
- `PLAN.md`"当前能力"补第 22 条，`PROGRESS.md` 记录本功能。
- 验证基线：Rust 全量测试 + `clippy -D warnings`；`npm run check` + `npm run build`；手动/Playwright 冒烟（右键入口、建窗与换样本、五分区与空态、并排对比、跳转主画廊）。

## 注意事项

- 老库 `generation_seed/steps` 等参数可能为 NULL——并排对比表按"有则显示"处理，不阻塞。
- `vibe_signature` 空串（已扫描无 VIBE 标记）与 NULL 在比较时统一按空串处理。
- 分区结果排序统一按导入时间倒序，与画廊默认一致。
