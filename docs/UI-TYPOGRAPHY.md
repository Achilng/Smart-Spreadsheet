# 界面文字规范

依据用户提供的 `D:/Agent/playground/netease-song-list.html`，直接采用其中的字号、字重、行高与文字色值。该文件是网易云音乐 Windows 歌曲列表的复刻稿；本项目按信息角色复用参数，不将其描述为整套网易云页面规范。

| 角色 | 参考稿对应项 | 字号 / 字重 | 颜色 |
| --- | --- | --- | --- |
| 页面、面板、条目标题 | `.title` / `.title-content` | 14px / 500 | rgba(40, 50, 72, 1) |
| 常规内容、操作文字 | `body` / `.album` | 13px / 400 | rgba(40, 50, 72, .8) |
| 说明、描述、次要元信息 | `.artist` | 13px / 400 | rgba(40, 50, 72, .6) |
| 数量、行号 | `.song-list` / `.number` | 13px / 400 | rgba(40, 50, 72, .5) |
| 模型、VIBE 微型徽章 | `.badge` | 9px / 400 | 沿用功能色 |

- 普通界面文字行高 1.4，字间距 normal；标题与副文案之间使用参考稿的 2px 间隔（画廊卡片）。
- 微软雅黑为界面字体。颜色透明度写入 `color` 的 alpha，不通过父容器 `opacity` 同时淡化图标、边框和内容。交互的禁用、显隐、拖动透明度继续用于原有状态。
- 全局参数在 `src/app.css`，业务 CSS 引用 `--font-body`、`--font-title`、`--font-badge`、`--font-weight-body`、`--font-weight-title`、`--line-height-ui` 和 `--text` 至 `--text-4`。旧字号变量保留为兼容别名。
- 覆盖 React 主窗口、素材、分组、提示词界面、工具箱和对比窗口；白色页面、布局结构和功能提示色保留。
- 按用户此前确认，素材封面上的名称仍使用原有华文宋体 / 宋体、随卡片缩放的字号和浅色叠字。深色图片上的数量也保留浅色；卡片版本目录与复制浮层使用普通界面的 13px 文字。
- 提示词富文本编辑区的文档标题层级（24 / 17 / 15px）与用户显式加粗保留，正文采用 13px；文档段落沿用适合长文的行距。
- 画廊底部预留 48px，容纳 14px 标题和 13px 元信息，避免侵占下一行的间距。

后续修改应按角色选择已有参数。需要增加新的层级时，先找到参考稿中对应的依据。
