# 原图预览

入口：画廊选中图片，点击右侧详情图片上的“查看原图”。分组及重复项的图片详情也使用同一预览窗口。

## 显示与操作

- 初始以原比例完整显示图片，四周保留留白，小图不强行放大。适合窗口模式会随窗口大小及工具栏实际高度重新计算，不裁掉竖图或长图。
- 底部提供缩小、比例、放大、100% 原始尺寸和适合窗口；支持最高 800% 放大。滚轮围绕鼠标所在位置缩放，放大后可拖动到图片各边缘。
- 双击切换适合窗口 / 100%；`0` 适合窗口，`1` 原始尺寸，`+` / `-` 放大缩小，方向键平移，Shift 加快平移，Esc 关闭并将焦点还给打开入口。
- 顶部显示文件名、图片尺寸和原图加载状态，并保留原图拖出、保存。铺满按钮只扩展当前预览到应用窗口范围，再次点击还原。
- 原图完成解码后才替换预览图。原图读取或解码失败时仍可看预览，点击重试会重新请求原图，避免反复使用损坏的缓存。

## 实现与回归

原有组件首次 effect 执行时 Portal 内的画布节点尚未挂载，尺寸监听未绑定；尺寸保持零值，缩放回退为 100%，高度超出画布时被裁掉。现在用实际节点作为监听依赖，初次同步测量并通过 ResizeObserver 跟随变化；未取得尺寸前不展示未适配的图片。工具栏固定占位，图片绝对定位，不反向撑大画布。滚轮监听使用非 passive 处理，缩放不会滚动底层画廊。

- `src/lib/images/lightbox-geometry.ts`：完整适配、平移边界、缩放中心计算。
- `src/react/ui/DetailLightbox.tsx`、`detail-images.css`：预览交互、解码与样式。
- `tests/lightbox-geometry.test.ts`：横 / 竖 / 极端比例、多尺寸适配、鼠标下的图像坐标保持、边缘可达与还原居中。
- 开发模拟页 `?mock=1` 的原图现在使用行记录的实际尺寸；`&originalShape=tall` / `wide` 生成 512×8192 / 8192×512 画布，`&brokenOriginal=1` 模拟首次收到损坏图片，重试恢复；`&failNext=get_row_original` 可模拟读取失败。均为浏览器内生成的测试图，不访问真实资料库。

本次通过类型检查、生产构建和 44 项前端单元测试；浏览器检查横竖原图、长图、缩窗、缩放 / 拖动 / 还原 / 焦点及损坏原图重试。原生拖出和保存对话框沿用现有接口，未在此次模拟验证中触发。
