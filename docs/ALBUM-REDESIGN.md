# 分组、素材与重复项相册界面

## 范围

分支：`feat/album-groups-materials`。主窗口的画廊、分组、素材、表格、文档、重复项统一使用左侧导航、白色背景、淡蓝选中态和黑色主要按钮，切换页面保持同一套框架。画廊保留原有图片卡片和浏览方式；分组、素材、重复项使用相册展示，素材大小调节独立于画廊。

## 使用

- 所有视图从左侧导航切换，顶部保留搜索、历史和导入导出。画廊、表格、分组、重复项共用可展开的“图片筛选”侧栏，默认收起，折叠不清除已选条件；素材保留独立素材筛选，文档保留文档目录。
- 分组默认进入书架；封面最多展示三张组内图片，悬停展开并轻微跟随鼠标，键盘聚焦也能展开。单张、空相册和未分组都有对应状态。
- 点击相册进入独立的组内浏览：标题栏仅显示返回箭头、分组名、图片数、图片筛选和分组操作，下面直接展示原有图片列表；保留选择、右键操作和详情。返回箭头回到书架并保留分组搜索；组内不显示书架搜索 / 排序 / 模式切换及重复的折叠标题。书架首页的“列表”切回原有分节浏览，从列表点击“书架”回到相册总览。
- 顶部搜索分组名称；“图片筛选”展开原有图片筛选栏；“新建 / 管理分组”支持新建、重命名、合并和删除。
- 重复项默认进入书架，按画师串 / 正向提示词 / VIBE 引用展示每组相册，保留按数量 / 名称排序及列表视图。进入相册后显示返回、该组名称、图片数、筛选和重命名操作；组内全选仅选择该组全部图片，列表和书架总览的全选仍覆盖所有重复组。返回或切换布局清除旧选区，别名同步到标题和封面，历史返回保存布局模式。
- 素材将固定封面与各版本独立图片组成相册；没有独立图片的版本共用封面，不重复计入图片数。只展示最多三张封面预览，完整图片及版本仍可在详情中查看。
- 单击素材查看详情；详情顶部版本按钮切换展示图。点击版本数量或右键相册打开版本目录，选择版本会切换并复制文本，双击相册复制当前版本。目录支持方向键、Home / End、Escape，超过八个版本提供搜索。
- 素材与分组共用页面标题、数量和相册名称样式：微软雅黑，标题 24px / 600，名称 15px / 600。默认相册封面上限均为 130px，圆角和展开效果相同；素材尺寸滑块可按需放大，虚拟滚动高度同步调整。Tag、图片数、版本数常驻。顶部提供常用 Tag，多选仍为同时匹配；“筛选”打开完整 Tag 列表。导入、编辑、删除及资料库保存流程沿用现有逻辑。

## 数据与性能

- 相册进入 / 返回采用 [View Transitions](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition)：三张叠图按图片 ID 与网格的同一张图衔接，其余可见卡片错峰铺开 / 收拢。书架名称随书架退场 / 恢复，不再飞向页头；详情标题、返回按钮和数量在固定位置以 150ms 淡入并最多上移 4px，返回原位淡出。主段 520ms，最多 24 张卡片参与。深层滚动时只匹配真正可见的同一张图，不改变滚动位置来迁就动画；返回复用已加载成员的前三张封面。预取最多等待 140ms，慢请求继续显示原有加载状态；减少动态效果直接切换，不支持 API 时使用短促的位移缩放回退。动画期间切走会取消并清理临时标记，进入 / 返回焦点使用 preventScroll。
- 分组与重复项的书架、列表、各个相册分别记住会话内滚动位置；重复项还按判断依据区分，分组总览按搜索 / 排序区分。进入新相册从顶部开始，返回书架和再次进入已浏览相册恢复各自位置。分组的布局和搜索随主视图切换保留，并写入前进 / 后退快照；换库清空分组搜索。
- 不复用目的地不同的滚动容器，加载时屏蔽浏览器自动钳制的位置记录，卸载取消旧恢复。图片卡片预留稳定的缩略图 / 两行文字高度，保留卡片级离屏优化，移除整组 500px 估算高度，避免列表重新展开时的滚动锚定跳动。
- 不改变数据库、原图、素材文本、版本保存顺序或现有资料库文件。
- 分组与重复项共用封面组件，只在接近可见区域时查询前三行，最多四个并发请求；离开时丢弃过期结果，图片错误可重试。重复项封面使用与组内相同的判断依据和筛选条件，切换时重新加载。删除或合并后移除已经不存在的打开分组。
- 最近 96 本相册的前三张封面数据保留在有界缓存中，按分组 / 重复项、来源版本、判断依据和相册身份隔离；返回书架直接复用，筛选 / 编辑 / 换库触发版本失效。过渡前固定正在展开的封面姿态，交接前最多等待 80ms 解码可见图片；标题宽度始终一致，去掉过渡结束时会再次播放的旧列表淡入，避免透明闪烁和封面占位闪烁。
- 素材保留分页、虚拟滚动和图片缓存，缓存保留集包含相册正在显示的版本图片；版本再多也不会一次请求全部配图。
- 动效只修改 transform，不改变邻居位置；系统减少动画设置禁用过渡及鼠标倾斜。
