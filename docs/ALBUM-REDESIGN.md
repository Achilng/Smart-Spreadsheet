# 分组与素材相册界面

## 范围

分支：`feat/album-groups-materials`。主窗口的画廊、分组、素材、表格、文档、重复项统一使用左侧导航、白色背景、淡蓝选中态和黑色主要按钮，切换页面保持同一套框架。画廊保留原有图片卡片和浏览方式；分组、素材使用相册展示，素材大小调节独立于画廊。

## 使用

- 所有视图从左侧导航切换，顶部保留搜索、历史和导入导出。画廊、表格、分组、重复项共用可展开的“图片筛选”侧栏，默认收起，折叠不清除已选条件；素材保留独立素材筛选，文档保留文档目录。
- 分组默认进入书架；封面最多展示三张组内图片，悬停展开并轻微跟随鼠标，键盘聚焦也能展开。单张、空相册和未分组都有对应状态。
- 点击相册进入组内，继续使用原有组内图片列表、选择、右键操作和详情；“所有分组”返回书架。“列表”可切回原来的分节浏览。
- 顶部搜索分组名称；“图片筛选”展开原有图片筛选栏；“新建 / 管理分组”支持新建、重命名、合并和删除。
- 素材将固定封面与各版本独立图片组成相册；没有独立图片的版本共用封面，不重复计入图片数。只展示最多三张封面预览，完整图片及版本仍可在详情中查看。
- 单击素材查看详情；详情顶部版本按钮切换展示图。点击版本数量或右键相册打开版本目录，选择版本会切换并复制文本，双击相册复制当前版本。目录支持方向键、Home / End、Escape，超过八个版本提供搜索。
- 素材名称在相册下方，保留宋体；Tag、图片数、版本数常驻。顶部提供常用 Tag，多选仍为同时匹配；“筛选”打开完整 Tag 列表。导入、编辑、删除及资料库保存流程沿用现有逻辑。

## 数据与性能

- 不改变数据库、原图、素材文本、版本保存顺序或现有资料库文件。
- 分组只在接近可见区域时查询前三行，最多四个并发请求；离开时丢弃过期结果，图片错误可重试。删除或合并后移除已经不存在的打开分组。
- 素材保留分页、虚拟滚动和图片缓存，缓存保留集包含相册正在显示的版本图片；版本再多也不会一次请求全部配图。
- 动效只修改 transform，不改变邻居位置；系统减少动画设置禁用过渡及鼠标倾斜。

- TypeScript 检查、前端生产构建、41 项前端单元测试通过（新增三项素材图片去重、回退及加载上限测试）。

- 前端控制台未出现错误；生产构建保留现有的大 chunk 提示。不替换本机安装版，不发布 Release；真实资料库和打包后的桌面窗口尚未进行此次专项验收。
