# 外置 LLM 画风提取

## 约定

- 只处理资料库当前正向正文，UTF-8 原文完全相同才合并；不清洗、不排序、不拼接角色提示词。
- 智能表格导出 request v1；外部本地网页通过 Codex CLI 的 `gpt-6-luna` 处理；导入 result v1。
- ID 为 `sha256:` + 正文 UTF-8 SHA-256 小写十六进制。结果包含原文，导入以哈希和全文共同匹配当前资料库。
- `ok` 必须为非空连续原文子串；`none` 必须为空；`error` 不应用。外部脚本复制原文和来源信息，模型仅返回 ID / status / artist_string。
- 每次调用数量可配置，默认 10；另有文本长度限制；不截断单条正文。串行调用，有限重试、暂停、续跑；任务状态持久化，网页断线自动重连。
- LLM 结果随资料库保存，空结果也有效。正向正文变化失效，角色/负向/备注/Tag 变化保留。导入预览后事务应用，撤销同时恢复来源。

## 开发与验收

1. 外部网页、处理脚本、固定提示词、协议与断点恢复测试。
2. 数据库 v21、结果校验、导出、预览、应用和撤销；覆盖旧自动重算路径。
3. 工具箱入口、选区/筛选/全库导出、预览、表格与详情 LLM 标记。
4. 现有检查与必要回归；Codex 小样本实际调用和浏览器流程验证。
