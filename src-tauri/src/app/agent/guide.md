# 智能表格功能地图

- 主窗口最左边是视图导航：「画廊」「分组」「素材」「表格」「文档」「重复项」；底部固定「导入」「导出」「助手」「工具箱」。
- 顶部栏有后退/前进和搜索框。画廊、表格上方有大小滑块、排序菜单和「图片筛选」按钮（在图片区左边展开筛选栏）。
- 单击图片，右侧显示详情面板；勾选图片后底部出现批量操作栏；图片上右键有常用菜单。
- 独立窗口：「工具箱」（批量工具、AI 设置、更新）、图片对比窗口（右键「对比」打开）、整理助手（点「助手」打开）。

## 导入与更新图片

- 左下「导入」→「导入文件夹」或「导入压缩包」（zip / 7z / rar）；也可把 PNG、文件夹、压缩包拖进主窗口。已入库的图片会跳过；刚导入的一批可按 Ctrl+Z 撤销。
- 没有 NovelAI 生成信息的图片不会入库，会被移到「失败图片目录」（导入文件夹时会从原文件夹移走），在 工具箱 →「资料库维护」→「打开目录」查看。
- 「导入」菜单的「导入时自动补全画师前缀」：打勾后，新图片里库内已有 artist: 证据的裸画师名会自动补前缀。
- 「导入」→「更新现有图片」：原图改过或搬家后重新读取生成信息，只更新已有记录、不新增，保留 Tag 和分组；有图片被更新时会清空撤销记录。
- 导入后会自动执行勾了「新图片导入后自动执行」的自动规则，开了「导入图片时自动提取」时还会做 LLM 提取。

## 浏览视图

- 「画廊」是缩略图墙；「表格」一行一张，列出图片、时间、提示词、画师串。「分组」「重复项」是相册（书架），可切换列表。
- 排序菜单：「时间正序」「时间倒序」「最近更新」，会记住。
- 看大图：点详情里的预览图（「查看原图」），滚轮缩放、拖动、双击切换适合窗口/原始尺寸，Esc 关闭，顶部有「保存」「拖出」。图片也可直接拖到其他软件。
- 后退/前进：顶部箭头、Alt+←/→ 或鼠标侧键，回到之前的浏览和筛选状态。

## 搜索与筛选

- 顶部搜索框搜文件名、提示词、画师（素材页里搜素材）。
- 「图片筛选」打开左侧「筛选」栏：「仅显示收藏」「按正向提示词去重」「按画师串去重」；「过滤」弹窗可按 Tag、分组、画师、提示词、VIBE、备注、元数据、构图、尺寸、生成参数设条件，点「应用过滤」；下方 Tag 列表勾选筛图，「AND」全部包含、「OR」任意包含。
- 生效的条件显示在图片上方，点 × 去掉单个，「清除全部」全清并回到原来的浏览位置。
- 右键「只看当前画师串」；详情画师串旁的漏斗按钮也能筛相同画师串。

## 勾选与批量操作

- 点缩略图的勾选框或 Ctrl+点击勾选，Shift 连选，Ctrl+A 全选当前视图，Esc 取消。
- 底部操作栏：「取消选择」「仅看所选图片」「全选当前视图」「编辑 Tag」「更多操作」（「收藏」「移入分组」「编辑提示词」「删除所选」）「导出所选」。
- 「仅看所选图片」只显示这批图，点顶部条件标签的 × 恢复。
- 「编辑提示词」有「查找替换」和「修正画师前缀」两个页签。

## 右键菜单

- 图片上右键：「复制 Prompt」「导出原图」「复制文件地址」「在文件管理器中打开」「对比」（勾了两张时为「对比这两张」）「只看当前画师串」「选中相同画师串」「设为/取消画师串代表图」「编辑 Tag」「移入分组」「编辑提示词」「删除」。
- 已勾选多张时，后四项作用于全部勾选的图；右键没勾选的图会改为只选它。

## 详情面板与编辑提示词 / 备注

- 右上角箭头收起/展开；标题旁「…」→「删除图片」。
- 顶部 Tag 条：点「添加标签」/「标签」或「+数量」，搜索、添加、移除、新建 Tag，即时保存。
- 预览图右上角「设为代表图」；下方「分组：…」下拉改分组，「添加备注」/「备注」展开备注。
- 「正向提示词 / 画师串」切换：正向提示词页用铅笔按钮编辑、复制、「展开全文」；画师串页可筛选、复制。画师串没有编辑按钮，会随提示词自动更新或由 LLM 提取写入。
- 折叠区：「角色提示词」（多角色分「角色 1」「角色 2」显示）、「负向提示词」、「更多信息」（生成参数、文件路径）。
- 编辑时 Enter 保存、Shift+Enter 换行、Esc 取消，可 Ctrl+Z 撤销。只改资料库，原图文件不变。

## TAG 管理

- 加/减 Tag：勾选后底部或右键「编辑 Tag」，搜索或新建（逗号分隔多个），点 Tag 切换待添加/待移除，再「应用」。单张可在详情 Tag 条直接改。
- 改名/删除：「图片筛选」的 Tag 列表里右键 Tag →「重命名」或「删除 Tag」。删除只从所有图片和素材上拿掉这个 Tag，可撤销。
- 按提示词组合批量打 Tag：见「快速整理」。

## 分组

- 移入：勾选后「更多操作」或右键 →「移入分组」，选已有分组、「新建并分配」或「取消分组」；单张用详情「分组：…」下拉。
- 浏览：左侧「分组」，可搜索、按图片数排序、书架/列表；打开后用「组内图片排序」。
- 管理：「新建 / 管理分组」可新建、重命名、合并、删除、「清理空分组」；或右键分组相册 →「重命名」「合并到…」「删除分组」。删除分组时图片回到「未分组」，不会被删。

## 快速整理

- 工具箱 →「快速整理」，模式：「添加 Tag」「批量分组」「提示词操作」。扫描整个资料库，做完可「撤回」。
- 输入提示词组合（逗号或换行分隔，每项都要出现，忽略大小写和权重），选 Tag 或目标分组（可「＋ 新建」），「预览匹配结果」后「执行打标」/「执行分组」。
- 「提示词操作」：输入一个画师名，「修正前缀」补上 artist:。

## 收藏与画师串代表图

- 收藏：画廊里鼠标移到图片上点右上角星星，再点取消；批量：「更多操作」→「收藏」（只能添加）。查看：「图片筛选」→「仅显示收藏」。收藏不能 Ctrl+Z 撤销。
- 代表图：右键「设为画师串代表图」或详情预览图右上角「设为代表图」；「按画师串去重」时该组优先显示它。每组只能一张，已有时可选「查看已标记图片」或「替换为当前图片」；没有画师串的图不能设。

## 画师串（识别、前缀修正、LLM 提取、白名单）

- 画师串是从正向提示词里认出的画师/画风部分；没写 artist: 时整段正向提示词就当画师串。筛选、去重、重复项、对比都用它判断“同一画风”。
- 补 artist: 前缀：工具箱 →「画师前缀修正」→「扫描裸画师 Tag」→ 勾选后「为所选画师补全前缀」（只处理库内某处明确写过 artist:xx 的同名 Tag）；「处理纯文本」只转换粘贴的文字。其他入口：「快速整理」「编辑提示词」、导入时自动补全。
- LLM 提取：工具箱 →「LLM提取」。先在「渠道设置」配好 Key，再在「提取任务」选范围（全部资料库 / 主窗口选中图片 / 当前筛选结果），点「开始后台处理」。可暂停、继续、「重试失败项」、「撤销本任务写入」；顶部栏显示进度。「JSON 导入 / 导出」页签可和外部工具交换数据。
- 白名单（比较画师串时忽略的词，如质量词）：在详情、表格、对比窗口的画师串里拖选文字 → 右键「将这些tag加入白名单（所有图片生效）」或「取消加入白名单」，白名单词显示浅橙色底。也可在「LLM提取」→「复用白名单」编辑后「保存设置」；归类不对时点同页「刷新画风归类」。原文不会被改。
- 随机画师串：工具箱 →「随机画师串」，勾「库内画师」/「自定义名单」，「生成」后「复制」。

## 重复项与别名

- 左侧「重复项」把相同内容的图片归组，依据可选「按画师串」「按正向提示词」「按 VIBE 引用」；打开后用「组内图片排序」。
- 别名：右键重复项相册 →「重命名」；留空保存恢复原名，不影响归类。
- 在画廊每组只看一张：「图片筛选」→「按画师串去重」或「按正向提示词去重」。

## 图片对比

- 右键图片 →「对比」；正好勾两张时 →「对比这两张」（先勾的是 A）。
- 左侧是样本 A 和关系：「相同画师串」「相同 VIBE」「相同提示词」「不同模型」（只查最新 500 张同画风图片）。点结果进入并排对照。
- 并排页切「正向提示词」「角色提示词」「负向提示词」「生成参数」、「只看不同」；← → 换目标，Esc 返回；可「查看原图」「定位」到主画廊。
- 「自定义对比」：选「要比较什么？」，勾选允许不同的条件，可「对结果去重」。「手动选择 B」：回主画廊挑图后点「使用这张图作为 B」。

## 以图搜图

- 工具箱 →「以图搜图」：「选择图片…」或拖入参考图，点「搜索相似图片」，点结果可在主画廊定位。
- 结果不全时先到「资料库维护」点「刷新感知哈希」的「开始刷新」。

## 素材库

- 左侧「素材」：保存常用文本，每份有名称、封面、Tag 和多个版本。
- 「新建素材」→ 名称、Tag、封面（「去画廊选择」/「从本地文件选择」）、版本文本（「新增版本」「设为默认」等）→「保存素材」。也可「导入图片」或把图片拖进素材页，从生成信息里挑文本。
- 单击卡片选中，双击复制当前版本；点「N 个版本」或右键卡片切换版本；小眼睛「查看详情」里可「复制」「编辑」「删除」（不能 Ctrl+Z 恢复）。

## 提示词文档

- 左侧「文档」：整理提示词、插图，自动保存。左栏「新建」、搜索；工具栏有标题、粗体、列表、「插入图片」、撤销/重做。
- 「复制全文纯文本」；「删除」会连插入的图片一起删，不可撤销。

## 自动规则

- 工具箱 →「自动规则」（工具箱默认页）。「新建」→ 名称和触发时机（「启用规则」「新图片导入后自动执行」「更新现有图片后自动执行」）→ 条件组（AND/OR）→ 任务（加/删 Tag、分组、追加/删除/替换/正则替换提示词、修正 artist: 前缀、备注等）→「保存规则」。
- 「测试现有资料库」只预览；「应用到现有图片」会真改，不进撤销记录且清空撤销记录。
- 可调顺序、勾选启停；「导入 JSON」「粘贴 JSON 文本」「导出 JSON」「复制 AI 编写提示词」。导入的规则默认停用。

## 导出（图片、表格、JSON）

- 有勾选时导出已选图片，否则导出当前筛选结果。入口：左下「导出」或底部「导出所选」：「导出 xlsx」（带图片的 Excel）、「导出智绘姬 JSON」、「导出为轮询脚本 JSON」（需先勾选）、「导出图片（复制）」「导出图片（硬链接）」（在所选位置新建输出文件夹）。
- 智绘姬 JSON 选项：「名称使用“备注_序号”」「将画师串视作正向提示词导出」（默认勾，空画师串跳过）「按最终正向提示词去重」。
- 单张：右键「导出原图」或原图查看器「保存」。
- 改名或去掉生成信息：工具箱 →「导出工具」，选图 → 导出位置 →「重命名」→「抹除元数据」→「开始导出」，原图不变。
- 工具箱 →「智绘姬 JSON 去重」：「选择 JSON 文件」→「检查 JSON」→「去重并另存为…」。

## 删除图片与回收站

- 入口：右键「删除」；「更多操作」→「删除所选」；详情「…」→「删除图片」；选中后按 Delete；对比窗口右键。
- 会删除记录及其 Tag、分组关系、库内副本和缩略图。「同时将原始图片文件移入回收站」默认勾选，会把电脑上的原图移进 Windows 回收站（应用内无法恢复，可去回收站还原）；不想动原图就取消勾选。压缩包导入的图片会跳过。
- 删除不能 Ctrl+Z 撤销，还会清空撤销记录。整理助手不能删除图片。

## 撤销与历史

- 主窗口：Ctrl+Z 撤销，Ctrl+Y 重做（没有按钮），最多 50 步，只在本次运行有效；素材和文档页不响应。
- 可撤销：Tag、提示词、备注、分组、批量替换、导入一批图片等。不能撤销：删除图片、「更新现有图片」、自动规则「应用到现有图片」（这三项还会清空记录）、删除素材/文档、「重置表格」、收藏。
- 工具箱顶部「↶ 撤回」「↷ 重做」只管工具箱里的批量修改，关闭工具箱后清空。
- LLM 提取用「撤销本任务写入」；整理助手用「操作记录」。

## 资料库与数据目录、维护

- 首次启动选「新建数据目录」或「打开已有数据目录」。资料库保存图片资料、缩略图、整理结果和 AI Key。运行中没有切换资料库的入口（只在启动页或打开失败时「重新配置」）。
- 工具箱 →「数据管理」：「迁移资料库」→「选择迁移目标…」（空文件夹，复制校验后自动切换）；「重置表格…」清空数据库、库内副本和缩略图，外部原图不删，不可撤销。
- 工具箱 →「资料库维护」：「刷新感知哈希」、「失败图片目录」。

## 工具箱一览

- 常用工具：「LLM提取」「自动规则」「快速整理」「画师前缀修正」「随机画师串」「以图搜图」；文件处理：「导出工具」「智绘姬 JSON 去重」；资料库维护：「资料库维护」「数据管理」；应用：「应用更新」。图库为空时部分工具不可用。

## 模型设置（AI 渠道和 Key）

- 整理助手和 LLM 提取共用渠道。入口：工具箱 →「LLM提取」→「渠道设置」（部分提示里叫“模型设置”，就是这里）。
- 「新增渠道」→ 填「渠道名称」「Base URL」「API Key」「模型」（可「获取模型列表」），勾「启用此渠道」→「保存设置」。
- 没保存 Key 时会弹提醒：「去填写 Key」跳到渠道设置；「我是衣衣，帮我一键配置！」给大宇宙站用户只填 Key；或「稍后再说」「不再提醒」。
- Key 以明文存在资料库里，复制资料库到别的电脑可继续用；分享资料库前先「清除 Key」。
- 助手模型：点助手输入框下方的模型名称（未选时为「选择模型」），选渠道、模型和「思考强度」后「保存」。需要支持 Responses 接口和工具调用的模型，看图还要支持图片。

## 软件更新

- 工具箱 →「应用更新」→「检查更新」→「下载并安装」，装好后自动重开。有任务在进行或工具箱还有可撤回的修改时会被拦住。也可到 GitHub Release 页面下载 .exe 手动安装。

## 整理助手

- 入口：主窗口左下「助手」（图库为空时不可用）。
- 能做：找图、统计提示词/画师/模型参数和各种张数分布、看图（可放大看局部）；在主窗口选中图片、设筛选、「仅看所选图片」、切换视图和排序、打开分组/详情/对比窗口；批量改 Tag、分组、备注、正向/角色/负向提示词、收藏、补 artist: 前缀；重命名、合并、删除分组和 Tag，设画师串别名和代表图；你明确同意时新建、修改、启停、删除自动规则，或把规则在已有图片上试跑。不能删图，不做导入导出，不改软件设置。
- 改动先出“修改预演”卡片，点「确认执行（N 张）」才生效；之后可「撤销这次修改」。原图文件不会被改。
- 左栏「操作记录」保留最近 100 次修改，重启后也能撤销；之后又被改过的图片保持现状。
- 附件：回形针、拖入或粘贴截图，每条最多 4 个，支持 PNG、JPEG、WebP、PDF、文本。图片只存在本地对话，不导入图库；发 NovelAI 生成的 PNG 可让助手读出提示词和参数。
- 左栏「新对话」；对话旁「…」可「重命名」「删除对话」（不撤销已做的修改）。回复中可点停止，已完成的修改保留。
- 复杂的查找和统计（多个条件组合、几个特征里至少中几个、跨分组/Tag 统计）助手会自己写只读查询来查，只读不改；要改的话照样先出预演卡片。
- 输入框右下角的小圆环是「上下文」剩余量，鼠标移上去看已用多少。快满时助手会自动把较早的对话整理成一段摘要再继续（对话里会出现一条「较早的对话已整理成摘要」的分隔线，点开能看摘要）。上下文长度在助手的模型设置里改，默认 200k。
