# 画风批改台（开发者自用）

智能表格「工具箱 → 画风网页工具 → 画风批改台」可一键启动服务并在默认浏览器打开；也可从「LLM 画风提取」页面进入。工具箱入口需要本机已有 Node.js 22 或更高版本，不会自动安装。没有导入图片时也可使用侧栏入口。

双击 `启动批改台.cmd`，浏览器打开 http://127.0.0.1:17324，选择画风提取结果 JSON。也可把 JSON 拖到启动脚本，或运行 `node tools/style-review/server.mjs "结果文件路径"` 预先载入文件。

- 左侧原文高亮模型提取的连续片段，右侧单独显示结果；保留空白、换行和权重。可定位提取段。
- 正确 / 错误 / 待定，支持快捷键 1 / 2 / 3，左右方向键切换；默认判定后自动下一条。可撤销当前判定、筛选错题或跳到下一条未批改。
- 正确率 = 正确 /（正确 + 错误）。待定、未批改和模型调用失败不进入分母；统计的是当前已批改样本，不推算全库准确率。
- 备注与人工参考答案选填；启用参考答案后留空表示应当无画风，不启用表示尚未填写。它们不修改模型结果。
- 浏览器自动保存批改和位置；再次打开同一数据恢复。导出批改记录 JSON 可备份或跨浏览器恢复，文件内自带原始结果；重新打开时按每条修改时间保留较新批改。错题可导出为可直接阅读的 TXT。
- 页面只在本机运行，不调用模型，不上传数据，不改写输入文件。浏览器清理站点数据会清除本机进度，请用导出记录留存。

`STYLE_REVIEW_PORT` 可改端口，默认 17324。无需新依赖，使用已有 Node。
