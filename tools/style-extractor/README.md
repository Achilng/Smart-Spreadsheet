# 外置画风提取工具

1. 在智能表格「工具箱 → LLM 画风提取」导出待处理 JSON。
2. 双击本目录的 `启动画风提取.cmd`，或在项目根目录运行 `node tools/style-extractor/server.mjs`。
3. 浏览器打开 http://127.0.0.1:17321 ，选择 JSON，设置每次调用条数（默认 10），创建任务后点「开始 / 继续」。
4. 完成后下载结果 JSON，在智能表格同一工具页预览并应用。

需要已有 Node 和已登录的 Codex CLI；模型固定为 gpt-6-luna。工具不安装或升级环境。可先运行 `codex login status` 检查登录。调用消耗当前 Codex 登录方式对应的额度。

界面显示累计运行时间（不含暂停时间）、进度、调用次数、无画风和失败数量。每批完成保存到本目录 `data/`，请保留它；关闭网页不停止任务。点击暂停会停止当前调用，该批未保存的条目在继续时重新请求。关闭服务或电脑后，重新启动并选择历史任务继续；成功项不重跑。网页短暂断线会自动重连，服务重启后刷新网页即可。

每批条数为上限，长正文批次会缩小；单条不截断。可选择 low / medium / high 推理等级。临时失败最多自动尝试三次；登录、权限或额度错误暂停任务，解决后继续。失败项可单独重试。提示词变更后旧任务禁止继续，以免混用规则；仍可下载旧结果或创建新任务。

任务文件含原文，原文只通过 Codex CLI 发送给模型。HTTP 服务只监听 127.0.0.1，不对外网开放。

可选环境变量：`STYLE_PORT`（默认 17321）、`STYLE_DATA_DIR`（任务保存目录）、`STYLE_TEMP_DIR`（临时目录，默认 D:/Agent/Agent_temp/style-extractor）、`STYLE_CODEX_BIN`（Codex 可执行文件路径）。测试用临时目录与正式 data 分开。

验证：`node --test tools/style-extractor/core.test.mjs`。
